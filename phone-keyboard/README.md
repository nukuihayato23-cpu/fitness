# phone-keyboard

iPhone で打った文字を Windows PC に入力するツールです。日本語・絵文字・改行もそのまま入ります。

## 必要なもの
- Windows PC に **Python 3.8 以上**（https://www.python.org/ からインストール。追加ライブラリは不要）
- iPhone と PC をつなぐ USB ケーブル

## はじめの準備（1回だけ）
1. PC に **「Apple Devices」アプリ**（Microsoft Store）または iTunes を入れる
   → iPhone の USB ドライバーがインストールされます。
2. iPhone の「設定 → インターネット共有」で **「ほかの人の接続を許可」をオン**にする
   （この項目がない場合は契約プランでテザリングが使えません。その場合は下の「Wi-Fiで使う」を参照）

## 使い方
1. iPhone を USB で PC につなぐ（「このコンピュータを信頼しますか？」→ 信頼）
2. PC でこのフォルダを開き、アドレスバーに `cmd` と入力して Enter → 次を実行
   ```
   py server.py
   ```
   初回は Windows ファイアウォールの確認が出るので**「プライベート」と「パブリック」の両方にチェック**して許可してください。
3. 画面に表示された `http://172.20.10.x:8765/?t=...` を iPhone の Safari で開く
   （URL の `t=` は合言葉で、起動するたびに変わります）
4. PC で文字を入れたいアプリ（メモ帳、ブラウザなど）をクリックして選択しておく
5. iPhone で入力 →「送信」で PC に入力されます

| ボタン | 動作 |
|---|---|
| 送信 | 入力した文字を PC に打ち込む |
| Enter / ⌫ / Tab / Esc / Del / 矢印 | そのキーを1回押す |
| 送信後に Enter も押す | チャットなどに便利 |

## Wi-Fi で使う
PC と iPhone を同じ Wi-Fi につないで `py server.py` を実行し、表示された `192.168.x.x` の URL を開けば同じように使えます。

## うまくいかないとき
- **iPhone で開けない** → ファイアウォールで Python が許可されているか確認してください（「Windows セキュリティ → ファイアウォールによるアプリケーションの許可」）。
- **172.20.10.x が表示されない** → iPhone のインターネット共有がオンになっているか、Apple Devices アプリが入っているか確認し、ケーブルを挿し直してから `server.py` を起動し直してください。
- **管理者権限のアプリ（タスクマネージャーなど）に入力できない** → Windows の仕様です。コマンドプロンプトを管理者として実行してから起動してください。
