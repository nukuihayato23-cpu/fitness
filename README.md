# 筋トレ&食事ノート

目的・性別・年齢・体重・運動経験・週の回数・1回の時間から筋トレメニューを作り、トレーニング・食事・体重を記録するWebアプリです。

## 使い方
- `index.html` をブラウザで開くだけで動きます(ビルド不要)。
- データはブラウザの localStorage に保存されます。端末をまたいで共有はされないので、設定画面の「バックアップを作成」で定期的に保存してください。

## ファイル
- `index.html` … 画面の入れ物
- `data.js` … 種目・食品などのデータ
- `app.js` … メニュー作成ロジックと画面
- `style.css` … 見た目
